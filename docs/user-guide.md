# 使用手册

面向在页面上配爬虫的人。字段名与提示文案均来自前端源码（`frontend-vue/src/views/spider/templates/*.vue`、[helpTexts.js](../frontend-vue/src/config/helpTexts.js)），页面上鼠标悬浮 `?` 图标看到的即这些说明。

接口口径见 [api.md](api.md)。

---

## 1. 入口与导航

打开 `http://<host>:8088/` 直接进入系统——**本应用没有登录页，也没有权限区分**，任何能访问该端口的人都能改配置、跑任务、执行 SQL（详见 [security.md](security.md)）。

左侧菜单（[routes-spiderflow.js](../frontend-vue/src/router/routes-spiderflow.js)）：

| 菜单 | 路由 | 用途 |
| --- | --- | --- |
| 工作台 | `/dashboard` | 任务/数据库/系统三块状态与统计 |
| 爬虫列表 | `/spider_list` | 流程的增删改查、运行、定时、通知 |
| 全局变量 | `/variables_list` | 所有流程共享的变量 |
| 自定义函数 | `/functions_list` | 用 JS 写函数，流程里以 `${函数名(参数)}` 调用 |
| 数据源管理 | `/datasources_list` | JDBC 数据源 + 「数据库」详情抽屉 |
| 系统设置 | `/system_settings` | 运行参数即时生效 + 系统状态 |

菜单左上角 `menu-fold` 图标可整体收起（[detail.vue](../frontend-vue/src/views/spider/detail.vue) 所在的通用布局）。

> 「脚本管理」入口已隐藏：0.5.0 后端没有 `script/*` 接口（[routes-spiderflow.js:193-194](../frontend-vue/src/router/routes-spiderflow.js#L193)）。

## 2. 工作台

四块内容，全部只读：

- **任务概览**：流程总数/启用数/含 cron 数、累计执行次数、任务总数、进行中、今日、平均与最长耗时。
- **趋势图**：近 N 天（接口 `days`，默认 14，范围 1-90）任务数与进行中数量。
- **流程排行**：按累计执行次数取前 8。
- **最近任务**：取最近 10 条 `sp_task`，只有"进行中/已结束"两种状态——`sp_task` 表没有成功/失败字段，别指望它当执行结果看板（[DashboardController.java:185](../spider-flow-web/src/main/java/org/spiderflow/controller/DashboardController.java#L185)）。
- **数据库页签**：主库版本/字符集/表数量/占用字节、逐表行数（精确 `count(*)`，不是 information_schema 估算值）、每个数据源的连通性与探测耗时（3 秒超时）。连接信息只回显 `host:port/db`，不返回口令。

## 3. 爬虫列表

| 列 | 说明 |
| --- | --- |
| 名称 | 悬浮可看完整名称；建议唯一，任务列表按它展示 |
| 状态开关 | 是否参与定时调度；未设 cron 时打开也不会触发 |
| cron | 点击「编辑cron」弹窗设置；旁边显示未来 5 次触发时间（`/spider/recent5TriggerTime`） |
| 操作 | 详情（进编辑器）、通知、运行、任务、删除 |

- **运行**：立即手动跑一次，不影响定时计划。
- **任务**：该流程的所有运行实例，可进「执行日志」或「停止」。
- **删除**：不可恢复；历史 XML 与日志文件仍在 `spider.workspace` 下。

## 4. 流程编辑器（画布）

### 4.1 布局

```
┌ 顶部工具栏（返回/保存/测试/调试/撤销…） ─────────────┐
├ 左：组件栏（单列） ┬ 中：画布 ───────┬ 右：属性面板 ─┤
│                   │                │ (全局/参数/   │
│                   │                │  Cookie/Header│
│                   │                │  /节点字段)   │
├───────────────────┴────────────────┴───────────────┤
│ 底部：测试/调试输出窗（WebSocket 实时日志）           │
└─────────────────────────────────────────────────────┘
```

组件栏图标为 28×28 的单列（[detail.less:52-74](../frontend-vue/src/views/spider/detail.less#L52)），左侧栏宽 56px（[detail.vue:16](../frontend-vue/src/views/spider/detail.vue#L16)）。

### 4.2 顶部按钮

返回、保存、测试、撤销、反撤销、历史版本、全选、剪切、复制、粘贴、删除、XML 编辑（查看源码）、打印 XML、调试（进入单步）、下一步、停止。每个按钮悬浮都有提示（[helpTexts.js:95-118](../frontend-vue/src/config/helpTexts.js#L95)）。

- **保存**会同时生成一个历史版本，可在「历史版本」里恢复。
- **测试**跑一次完整流程，输出显示在底部窗口。
- **调试/下一步**为单步模式，配合死循环阈值 `spider.detect.dead-cycle`（默认 5000）。

### 4.3 放置节点

两种方式：

1. 从左侧组件栏**拖拽**到画布任意位置（拖动时显示 32×32 虚线预览框）。
2. 单击组件图标 → 在画布左上区域(80,80)插入一个默认节点，再拖动到目标位置。

节点插入后为 32×32（[spider-editor.js:333](../frontend-vue/src/libs/spidereditor/spider-editor.js#L333)），可用网格吸附对齐；画布背景是 8px 网格。

### 4.4 右键菜单

| 右键目标 | 菜单项 |
| --- | --- |
| 节点 | 复制 `Ctrl+C`、剪切 `Ctrl+X`、删除 `Delete`、断开该节点连线、粘贴、全选、撤销、重做 |
| 连线 | 复制、剪切、删除、反转方向、粘贴、全选、撤销、重做 |
| 空白画布 | 粘贴、全选、撤销、重做、适应画布 |

「开始」节点的剪切/删除被禁用（它是流程入口，删掉后整个流程不可执行）；无出边的节点「断开该节点连线」为灰态（[spider-editor.js:194-241](../frontend-vue/src/libs/spidereditor/spider-editor.js#L194)）。

### 4.5 连线

从节点边缘拖出即创建连线。连线上可设：

- **流转条件**：表达式为 `true` 才走这条线，例如 `${fetchCount < 3}` 做翻页回环。
- **流转特性**：普通线 / 异常流转线（上一节点抛异常时才走）。
- 线粗细/样式/颜色只影响显示。

## 5. 节点说明

画布上可见 11 种组件（定义在 [editor.js:8-69](../frontend-vue/src/libs/spidereditor/editor.js#L8)，另有隐藏的 `start` 节点，新建流程时自动放置）。

### 5.1 通用字段

所有节点都有**节点名称**（显示在画布与运行日志中）。

### 5.2 开始抓取（request）

| 字段 | 说明 |
| --- | --- |
| 请求方法 | GET/POST/PUT/DELETE 等 |
| URL | 支持 `${}` 表达式，可引用变量或上一节点 `resp` |
| 延迟时间 | 每次请求前等待毫秒数，用于限速 |
| 超时时间 | 单次请求超时，留空用默认 |
| 页面编码 | utf-8/gbk 等，留空按响应头识别 |
| 重试次数 / 重试间隔 | 失败重试策略 |
| 代理 | `http://user:pass@host:port` |
| 请求设置 | 多行表格：参数 / 头部 / Cookie / 表单项 / 文件 |
| 类型 + Content-Type + 内容 | 请求体：none/form/json/text/file |
| 其它勾选项 | 跟随重定向、TLS证书验证、自动管理Cookie、自动去重、重复不执行后续节点 |

响应写入变量 `resp`，常用 `${resp.html}`、`${resp.xpaths(...)}`、`${resp.jsonpath(...)}`。

**自动去重**按 URL 生效，状态持久化在服务端 `<workspace>/<flowId>/url.bf`；想重抓全部链接就删这个文件（[RequestExecutor.java:443](../spider-flow-core/src/main/java/org/spiderflow/core/executor/shape/RequestExecutor.java#L443)）。

### 5.3 定义变量（variable）

成对的**变量名 / 变量值**表格，变量值支持内置函数，如 `${extract.selectors(resp.html,'.name')}`。定义有先后顺序，后面的才能引用前面的；表格行可拖动换序。

### 5.4 循环（loop）

**次数或集合**（如 `${list.length(tweets)}`）+ **下标变量**（从 0 开始）+ 可选**开始/结束位置**。下游用 `${变量名[下标]}` 取值。

### 5.5 执行结束（forkJoin）

汇聚多条分支，标记该路径结束。

### 5.6 输出（output）

成对的**输出项 / 输出值**表格；勾选**输出全部参数**可把上下文所有变量作为本节点输出。

**数据输出**三种：

| 勾选项 | 需要的字段 | 行为 |
| --- | --- | --- |
| （默认不勾） | — | 只在运行日志/测试窗显示 |
| 输出到数据库 | 数据源、表名 | 每条输出插一行，要求表已存在且**输出项名 = 列名** |
| 输出到 CSV 文件 | 文件名、编码 | 服务端本地路径，每次运行新建文件；Excel 打开中文建议 UTF-8 BOM |

> 需要"表不存在就自动建表"请用下面的 **自动入库** 节点，而不是这里。

### 5.7 执行SQL（executeSql）

| 字段 | 说明 |
| --- | --- |
| 数据源 | 下拉来自「数据源管理」里注册的数据源名称 |
| 语句类型 | `select` / `selectOne` / `selectInt` / `insert` / `update` / `delete` / `insertofPk` |
| SQL 语句 | 支持 `${}` 变量表达式 |

返回规则（节点提示原文）：`select` → `List<Map<String,Object>>`；`selectOne` → `Map<String,Object>`；`selectInt` → `Integer`；`insert/update/delete` → `int`（批量为 int 数组）。SQL 中变量必须用 `# #` 包裹，如 `#${title}#`。结果存入变量 `rs`。

### 5.8 自动入库（autoSQL）— 本分支新增

取**上游「输出」节点**的输出内容，自动建表并批量插入，不需要写 SQL。

| 字段 | 说明 |
| --- | --- |
| 数据源 | 必选 |
| 数据库 | 目标库（MySQL 里即 catalog），留空用数据源连接串指定的库；下拉实时从该数据源读取 |
| schema | 分模式的数据库（PostgreSQL/Oracle/SQL Server）使用，MySQL 一般留空 |
| 表名 | 支持 `${}` 表达式；只允许字母、数字、下划线和中文，且不能以数字开头 |
| 批次大小 | 每多少行执行一次批量插入，默认 500 |
| 其它 → 自动建表 | 勾上=表不存在时按输出内容建表并推断列类型；不勾=要求表已存在且列名与输出一致 |

工作方式与限制（[AutoSQLExecutor.java](../spider-flow-core/src/main/java/org/spiderflow/core/executor/shape/AutoSQLExecutor.java)）：

- Map 或 `List<Map>` 的每个元素作为一行，键作为列名；标量输出作为所有行共有的列。
- 列类型按取值推断，同一列出现混合类型时退化为字符串；字符串列上限 `VARCHAR(5000)`（[:75](../spider-flow-core/src/main/java/org/spiderflow/core/executor/shape/AutoSQLExecutor.java#L75)）。
- 表名/库名/模式名/列名走白名单校验（[:66](../spider-flow-core/src/main/java/org/spiderflow/core/executor/shape/AutoSQLExecutor.java#L66)），**不合法时该节点告警跳过**（日志里搜"不合法"），不会把非法标识符拼进 SQL。
- 节点执行完会还原连接的 catalog/schema，避免污染连接池里其他任务的默认库（[:118-130](../spider-flow-core/src/main/java/org/spiderflow/core/executor/shape/AutoSQLExecutor.java#L118)）。

### 5.9 执行脚本（script）

**脚本名 / 脚本文件 / 结果编码 / 执行参数 / 结果变量**。脚本是服务端文件，路径相对脚本根目录；本仓库未提供脚本管理页面（菜单已隐藏），一般配合插件或预先放置的文件使用。

### 5.10 执行函数（function）

**函数名 + 执行参数**，调用「自定义函数」页里注册的 JS 函数，结果不保存为变量。

### 5.11 子流程（process）

选择另一个爬虫流程执行，**父子流程变量共享**；可设执行条件表达式。

## 6. 全局变量 / 自定义函数

- **全局变量**：名称/值/说明三列，所有流程可读，节点里用 `${变量名}` 引用。
- **自定义函数**：函数名（需唯一）+ 入参（`名称:类型`，逗号分隔）+ JS 源码。保存后在流程中以 `${函数名(参数)}` 调用。编辑器内是 Monaco，带 JavaScript 补全。

---

## 7. 数据源管理与「数据库」详情

### 7.1 数据源

字段：数据源名称、驱动（按类型自动匹配，可手改）、数据库连接（JDBC URL）、用户名、密码。保存前可「测试连接」。

> 口令以明文存在 `sp_datasource.password`，且 `/datasource/all` 接口会把它返回给前端——见 [security.md §3](security.md)。

### 7.2 数据库详情抽屉

列表每行的「数据库」链接打开右侧抽屉（1100px）：

```
[数据库 ▾] [schema ▾] [表名过滤]  ← 左侧：表列表（单击选中，高亮）
                                ← 右侧：表结构 | 索引 | SQL执行
```

- **数据库 / schema 下拉**：MySQL 下 schema 通常为空（MySQL 把库报成 catalog），这不是故障。
- **表结构**：列名、类型、长度、小数位、可空、默认值、注释、是否主键；同时列出主键与索引。
- **索引**：索引名、是否唯一、列顺序、升降序（`ASC_OR_DESC`）、基数。
- **SQL 执行**：Monaco SQL 编辑器；首次选中表会自动填入 `select * from <表名> limit 100`（仅当 SQL 框为空时）。结果表格 + 耗时；**单次最多 500 行、30 秒超时**，超出时结果里标注截断。

顶部有黄色提示条，明确写着这是直接作用在数据源上的高危操作。抽屉关闭即销毁状态，不会把选中的库留在页面上。

| 页签 | 内容 |
| --- | --- |
| 运行参数 | 8 项参数，每项显示当前值、配置文件默认值、说明；标「已自定义」表示值来自数据库覆盖 |

## 9. 测试与调试

1. 编辑器顶部「测试」→ 底部窗口实时输出日志（走 `/ws`）与抓取结果。
2. 「调试」进入单步，「下一步」逐节点执行，可观察每个节点后的变量快照。
3. 「停止」中断当前测试任务。
4. 运行日志里的中文乱码：先确认响应编码字段（request 节点「页面编码」），再确认服务端 `-Dfile.encoding=UTF-8`。

## 10. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 保存后没定时执行 | cron 为空 / 流程未启用 / `spider.job.enable=false`（本分支默认关） | 三处都确认，见 §3、§8 |
| 输出到数据库没数据 | 输出项名与表列名不一致 | 对齐列名，或改用自动入库 + 自动建表 |
| autoSQL 报"表名不合法"并跳过 | 表名含空格、短横线、以数字开头等 | 改成合法标识符，或用 `${}` 变量时确保取值合法 |
| 同一条 URL 不再抓取 | 命中 URL 去重 | 关闭「自动去重」或删除 `<flowId>/url.bf` |
| 动态渲染页面抓不到内容 | 直接 HTTP 拿不到 JS 结果 | 找接口 URL，或引入 Selenium 插件 |
| 数据源下拉里没有想要的库 | 未注册 | 先到「数据源管理」新建 |
| 数据库详情里表列表为空 | 选了没有表的库 | 切换「数据库」下拉 |
